### Rock Paper Scissors AI — Pattern-Based Strategy

Developed a Python-based Rock Paper Scissors player that analyzes an opponent’s previous moves to identify recurring patterns and predict their next move. The strategy uses historical move sequences to select the counter move and was tested against four different opponent strategies.

**Tools:** Python, unittest

**What I did:**

* Built a game-playing strategy that maintains opponent move history
* Implemented pattern detection using the opponent’s previous three moves
* Predicted the opponent’s most likely next move based on historical sequences
* Selected the counter move designed to beat the prediction
* Added randomized behavior when insufficient historical data was available
* Tested the player against four different bots over 1,000 rounds each
* Achieved win rates ranging from **56.7% to 99.8%** across the four opponents
* Created automated unit tests to verify that the strategy meets the required performance threshold
